Arquitectura

  • Entrada: 24 ratings de usuario + 24 one-hot de categoría = 48 features
  • Linear(48 → 64) → BatchNorm → ReLU → Dropout(0.3)
  • Linear(64 → 32) → BatchNorm → ReLU → Dropout(0.2)

  • Parámetros totales: 5,441

Detalles del Modelo · LSTM Multivariado (Keras / TensorFlow) ▾

Arquitectura

  • Entrada: secuencias 3D (muestras, 14 días, 33 features)
  • LSTM(256, return_sequences=True) → Dropout(0.4)
  • LSTM(128, return_sequences=True) → Dropout(0.4)
  • LSTM(64) → BatchNormalization → Dropout(0.4)
  • Dense(32, ReLU) → Dense(1, Linear)
  • Salida: demanda de pasajeros (regresión)

Features (33)

  • Numéricas: demanda_pasajeros (target lag), evento_especial
  • One-Hot País (22): Argentina, Australia, Brazil, …, Vietnam
  • One-Hot Hemisferio (3): N, S, T (tropical/monzónico)
  • One-Hot car_type (3): luxury_bus, tourist_van, train_express
  • One-Hot payment_method (3): cash, card, digital_wallet
  • Escalamiento: MinMaxScaler en rango (0, 1) — persistido en scaler_transporte.pkl

Configuración de Entrenamiento

  • Dataset: demanda_transporte_global.csv · 144,738 registros · 22 países · 2024-2025
  • Ventana temporal: 14 días · Split cronológico: 80% train / 20% test
  • Loss: MSE · Métrica: MAE
  • Optimizador: Adam (lr = 1e-3, clipvalue = 1.0)
  • Batch size: 64 · Épocas máx: 50 (early stopping época 25)
  • Callbacks: EarlyStopping(patience=5, restore_best_weights) + ReduceLROnPlateau(factor=0.5, patience=2, min_lr=1e-5)
  • Hardware: GPU (TensorFlow + CUDA)
  • Artefactos: modelo_lstm_transporte.keras, scaler_transporte.pkl

Componentes simulados en el dataset

  • Estacionalidad climática por hemisferio (verano N ×1.8, verano S ×1.9, monzones ×0.5)
  • Eventos especiales: Año Nuevo Chino (CN/VN/TH +200), Navidad global (+80), Golden Week Japón (+150)
  • Estacionalidad semanal: picos viernes/sábado (+30), valle domingo (-40)
  • Tendencia post-pandemia creciente + ruido gaussiano (σ=12)
  • Quincenas: bonus al método de pago preferido del país los días 15 y 30

Detalles del Modelo · ResNet50 (PyTorch, Transfer Learning) ▾

Arquitectura

  • Base: ResNet50 preentrenada en ImageNet (IMAGENET1K_V1)
  • Fine-tuning: congelados todos los bloques excepto layer4
  • Cabeza personalizada:
    Dropout(0.4) → Linear(2048 → 512) → ReLU → Dropout(0.3) → Linear(512 → 5)
  • Parámetros entrenables: 16,016,389 / 24,559,685 (65.2%)

Clases (5)

  • safe_driving Conducción segura
  • talking_phone Hablando por celular (crítica)
  • texting_phone Escribiendo en celular (crítica)
  • turning Volteando hacia atrás
  • other_activities Otras distracciones

Configuración de Entrenamiento

  • Dataset: Multi-Class Driver Behavior (Kaggle) · 7,276 imágenes · split 80/10/10
  • Tamaño imagen: 224×224 · normalización ImageNet
  • Augmentación: HorizontalFlip, Rotation(±15°), ColorJitter, RandomGrayscale(0.05)
  • Loss: CrossEntropy con class_weight balanceado
  • Optimizador: AdamW (lr = 1e-3, weight_decay = 1e-4)
  • Scheduler: ReduceLROnPlateau(patience=3, factor=0.3) + grad_clip = 1.0
  • Batch size: 32 · Épocas máx: 30 · Early stopping: patience = 6
